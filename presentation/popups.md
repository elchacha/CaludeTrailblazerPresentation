## cache-1h-tip
slide: 8
delay: 5000
theme: blue

🤖 <strong>Psst, petite info fraîche !</strong>
<!-- more -->
Depuis la version <strong>2.1.108</strong>, vous pouvez passer le TTL du cache de 5 min à <strong>1 heure</strong> 🕐<br><br>
Il suffit d'activer l'option :<br>
<code>ENABLE_PROMPT_CACHING_1H</code><br><br>
⚠️ Attention quand même — ça coûte <strong>2× plus cher en écriture</strong>.<br>
Utile sur les très longues sessions, moins pertinent pour un usage ponctuel 😉

## git-barrier-tip
slide: 10
delay: 5000
theme: orange-dark

🤖 <strong>Psst, petit détail important !</strong>
<!-- more -->
<br>Contrairement à <em>mon humain</em> qui vit sans repo git 😅...<br>
Si <strong>vous</strong> utilisez git, le <code>.git</code> agit comme une <strong>barrière</strong> — je m'arrête là, je ne remonte pas au-delà !<br><br>
<strong>Exemple :</strong><br>
<code class="block">C:\projets\        🚫 hors repo → ignoré</code>
<code class="block">C:\projets\app\    🛑 racine du .git → barrière</code>
<code class="block green">C:\projets\app\src\ ✅ je suis ici → je remonte jusqu'au .git</code>
<br>Sans git ? Je remonte jusqu'à <code>C:\</code> 😬<br>
Avec git ? Je reste bien sage dans le repo 😇
