Deux modes d'utilisation

CLI Mode Claude Code

Directement dans le terminal Claude Code, via des slash commands. Aucune dépendance supplémentaire hormis Python.

UI Mode interface web

Un serveur Flask local avec une interface graphique pour gérer les projets, éditer les slides et générer la présentation.

cd ui
python server.py
# → http://localhost:8888

Étape 1 — Créer le plan

/planMaker 5

Claude pose 4 questions interactivement :

SujetDe quoi parle la présentation ?
PublicCollègues techniques, direction, étudiants…
ObjectifConvaincre, informer, former, divertir…
TonSérieux, décontracté, humoristique, inspirant…

Génère ensuite work/<slug>/plan.md et ouvre le dossier dans l'Explorateur.

Étape 2 — Affiner le plan

Ouvre work/<slug>/plan.md et modifie-le librement. Tu peux enrichir le contenu avec des directives @xxx@ :

DirectiveEffet
@développe avec un exemple concret@Ajoute un exemple illustratif
@ajoute de l'humour@Injecte une touche humoristique
@donne des chiffres@Illustre avec des statistiques
@crée un visuel ASCII@Génère un diagramme en ASCII art

Les directives @xxx@ sont supprimées du contenu final après traitement.

Étape 3 — Générer les slides

/draft
/draft max=12
/draft max=12 html=true
OptionEffet
(aucune)Génère tous les slides nécessaires
max=NLimite à N slides
html=trueGénère aussi une preview.html navigable (sans serveur)

Génère les fichiers dans work/<slug>/slides/slide-XX.md. Relis-les, retouche-les, ajoute des @xxx@ supplémentaires si besoin.

Étape 4 — Générer la présentation

/present
/present --interactive
/present --slug=mon-projet prompt="thème sombre, slides aérées"
/present --slide=03
OptionEffet
(aucune)Détecte le projet, génère directement
--interactive / -iMode guidé : choisit le projet et le style interactivement
--slug=<slug>Cible un projet précis
prompt="..."Instruction globale de style (thème, ton, CSS)
--slide=XXRégénère un seul slide dans index.html

Résultat : work/<slug>/presentation/index.html — ouvrir dans un navigateur.

Structure des fichiers

work/<slug>/
├── plan.md ← Étape 1 : plan de la présentation
├── theme.json ← Étape 4 : thème Reveal.js généré par Claude
├── slides/
│   ├── slide-01.md ← Étape 3 : un fichier par slide
│   ├── slide-02.md
│   ├── preview.html ← (optionnel, avec /draft html=true)
│   └── ...
└── presentation/
     ├── index.html ← Étape 4 : présentation finale Reveal.js
     └── slides-final.md

Format d'un slide (slide-XX.md)

---
numero: 03
titre: Titre du slide
type: contenu
partie: 1
---

# Titre du slide

- Point clé 2
- Point clé 3

Types : intro · agenda · contenu · transition · conclusion · final
